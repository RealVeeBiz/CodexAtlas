# Bartender Extension (moved)

The bartender bar script now lives as a standalone resource:

**[`veebiiz_bartender/`](../../../veebiiz_bartender)**

It registers physical bottles, glasses, recipes, and the `bahama_bar` zone into `veebiiz_physicalitems` at runtime.

See that resource’s README for install and gameplay. The ox_inventory item list remains mirrored at [`items_ox_inventory.lua`](../../../veebiiz_bartender/items_ox_inventory.lua).
